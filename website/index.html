The Annotated Transformer

Attention

Attention maps a query and key-value pairs to an output. The model compares the query with each key, then uses the resulting weights to average the values.

We call our particular attention Scaled Dot-Product Attention. Queries and keys have dimension dk; values have dimension dv.

Onhand

This paragraph names the Q/K/V setup: compare queries to keys, then average values with the resulting weights.

MatMulScaleMaskSoftMaxMatMul QKV

In implementation, the attention scores are produced by multiplying the query matrix by the transposed key matrix, scaling by sqrt(dk), and normalizing with softmax. 

scores = torch.matmul(query, key.transpose(-2, -1))
scores = scores / math.sqrt(query.size(-1))
p_attn = scores.softmax(dim=-1)
return torch.matmul(p_attn, value)

Softmax turns the scaled scores into attention weights, so the final output is a weighted mixture of the value vectors.

Reading the page

Scaled dot-product attention compares every query with every key, divides the scores by sqrt(dk), applies softmax, then uses those weights to mix the values.

Attention(Q,K,V) = softmax(QKT / √dk)V
  1. Queries ask what each token is looking for.
  2. Keys describe what each token can match.
  3. The dot product gives the compatibility score.
  4. Scaling keeps large dimensions from making softmax too sharp.
  5. softmax converts scores into weights.
10:56 PM · Onhand · Page-grounded

What does the softmax step actually produce?

Softmax turns the scaled scores into a probability distribution over positions, so the output is a weighted average of the value vectors — more weight on the values whose keys matched.

The manicule, a small pointing hand in the margin, has meant "look here, this part matters" in books since the twelfth century. Onhand brings the gesture back, with the model holding the pen.
☞What it does

Four ways it helps you read.

Onhand stays out of the way until you ask.

☞

Points to the answer

Highlights the exact phrase or paragraph that answers your question and scrolls it into view.

✎

Leaves a note in the margin

Adds a sentence or two beside the highlight, so you can keep reading without losing your place.

⎘

Picks up where you left off

Every session is saved with its highlights, notes, and answers. Come back tomorrow and reopen it as you left it.

◔

Talk it through

Turn on Voice in Onhand's options (it needs an OpenAI API key), then press Voice in the side panel and talk about what you're reading. Onhand answers aloud and marks the page as it goes. Watch an early voice demo ↗

☞Install

Up and running in a minute.

  1. Add Onhand to Chrome from the Chrome Web Store.
  2. Open its options page and choose how to connect: Onhand Free (no account needed), OpenAI Codex sign-in, or your own API key.
  3. Open any page, click the Onhand icon, and ask a question.
☞ Add to Chrome

Or download the ZIP, unzip it, and load it from chrome://extensions with developer mode on. Release notes ↗
